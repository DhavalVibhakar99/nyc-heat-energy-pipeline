        How it works

        1. Ingest. An AWS Lambda pulls changed 311 heat complaints every morning, reconciling row counts against the city's API before anything is written.
        2. Warehouse. Files land in S3 and load into Snowflake. dbt dedupes complaints, normalizes LL84's six BBL formats and joins each complaint to the energy score that existed at the time.
        3. Test & publish. GitHub Actions rebuilds every model, runs the data tests and publishes this page. If a test fails, the page keeps yesterday's data.

        Rates pool complaints over floor area, so one huge building can't dominate. LL84 covers large buildings only. Correlation, not causation: a regression controlling for size and age found a small effect (−1.7% complaints per 10 ENERGY STAR points, not significant at 5%). Sources: NYC Open Data 311 Service Requests and LL84 Energy Benchmarking.
